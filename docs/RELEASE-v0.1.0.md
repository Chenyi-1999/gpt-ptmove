# v0.1.0 — 首个可部署版本

提供中文控制台、织梦 → NovaHD 月度规则、候选预览和批量任务、qB API NAS 执行端、PTNexus HTTP 发布适配、目标做种验证与恢复。默认 6 个/月、1–10 GiB、60 GiB 资源预算、做种人数至少 3，参数可调整。

公开接口采用独立执行端令牌，连接凭据加密保存，计划默认关闭；缺少域名时控制台仅监听 152 本机端口，以 SSH 隧道访问。

发布结果不确定会阻止重发和跨月重新入队；人工填写已发布链接后，只修复做种并核对目标文件指纹。领取过的任务保留下载预算，避免过期租约错误退款。

这是独立实现，通过 API 使用外部 PTNexus，不包含其代码或镜像。152 的 Docker/模拟验证与真实站点验证分开记录，详见 VALIDATION.md。上线使用前需接入 NAS、两站登录信息和 PTNexus，并完成单种联调。
